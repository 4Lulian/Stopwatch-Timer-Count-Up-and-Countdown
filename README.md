# Stopwatch-Timer-Count-Up-and-Countdown
פרויקט המאפשר למדוד זמן באמצעות סטופר, לספור קדימה ולהגדיר טיימר לספירה לאחור.
הסבר על הקוד- 
בתחילת התוכנית הגדרתי את החיבורים של שלושת הלחצנים ושל תצוגת ה7 סגמנט הלחצן הכחול מחובר לפין 2, הלחצן הירוק לפין 6 והלחצן האדום לפין 3. תצוגת ה־7 סגמנטים מחוברת לפינים 8 ו־9 ואז הגדרתי שני מצבים למערכת סטופר וטיימר במצב סטופר המערכת סופרת את הזמן קדימה, ובמצב טיימר המערכת סופרת את הזמן לאחור בנוסף הגדרתי משתנה שבודק אם המערכת כרגע פועלת או עצורה, בתחילת ההפעלה הגדרתי את הלחצנים כקלט והפעלתי את תצוגת ה־7 סגמנטים. המערכת מתחילה במצב סטופר ומציגה 0 בכול ה7 סגמנט, במהלך הפעולה המערכת כל הזמן בודקת האם אחד משלושת הלחצנים נלחץ.
כאשאני לוחצת על הלחצן הכחול המערכת עוברת בין מצב סטופר למצב טיימר והמעבר מתבצע רק כאשר הספירה אינה פעילה.
כשאני לוחצת על הלחצן הירוק ואני נמצאת במצב טיימר, אני יכולה לקבוע את זמן הספירה. בכל לחיצה הזמן גדל ב־5 שניות. 
וכשאני לוחצת על הלחצן האדום, הוא עושה עצירה ואיפוס של המערכת ואם המערכת לא פועלת הלחיצה מתחילה את הספירה ואם המערכת פועלת הלחיצה עוצרת אותה ומצב סטופר, בכל שנייה אני מגדילה את הזמן בשנייה אחת ולכן הזמן מתקדם קדימה.
